Для классификации ориентации текстовых кропов была построена вероятностная
система предсказания $p_{180}$. В ходе работы проведён технический аудит
тестовых данных, сформирована внешняя обучающая выборка из отфильтрованных
реальных COCO-Text кропов и синтетических русско-английских текстовых
изображений, а также протестированы компактные CNN MobileNetV3-Small и
ShuffleNetV2 x0.5.

Лучший результат на независимой парной validation-выборке показала открытая
специализированная модель PaddleOCR `PP-LCNet_x0_25_textline_ori`, решающая
задачу классификации направления текстовой строки $0^\circ/180^\circ.$
Для повышения устойчивости к слабоконтрастным изображениям был проверен набор
мягких методов preprocessing; CLAHE по L-каналу LAB-пространства показал
наилучший Brier score на фиксированной validation-подвыборке. В итоговом
pipeline исходный crop проходит CLAHE-preprocessing, затем обработку
PaddleOCR-классификатором, после чего confidence предсказанного класса
преобразуется в вероятность $p_{180}.$ Итоговый файл `submission.csv`
содержит 20 000 строк и соответствует требуемому формату.
